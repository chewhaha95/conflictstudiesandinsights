# CSI Biweekly Conflict Insights — editing rules

Site: https://conflictstudiesandinsights.pages.dev (Cloudflare Pages, deploys `main`).
Each edition is a dated page (e.g. `15-28-sep-2026.html`); the current edition is also copied to `index.html`.
Weekly Brief pages (Apr–Sep 2026) are an archive and are not edited.

## Conflict statuses (map data in each edition's script, `CONFLICTS` list)
- Statuses (Priority / Active / Watch) are set by the CSI editor. Change one only when the editor says so.
- Russia–Europe tensions (`RUS-EUR`) is Watch, confirmed by the editor on 8 Oct 2026.

## Confidence ratings (Key Learning Topics)
Keep this scale and its wording; it appears in the "How to read the ratings" box:
- **Preliminary** — An early observation from this fortnight. It may change as more reporting comes in.
- **High confidence** — Several independent, reliable sources agree.
- **Medium confidence** — Credible reporting, but key facts come from one side or have not been independently verified.
- **Low confidence** — Thin or single-source reporting. Treat it as a possibility, not a finding.

For every learning topic in every edition:
1. Use the editor's rating from the topic's "Learning status" line.
2. Check it against the scale using the topic's own sources (who reported it, whether it was independently verified). If they disagree, flag it to the editor rather than changing the rating.
3. Write the one-line "why" beside the rating chip from those sources, e.g. "reported by one side, not independently verified".
4. If a topic has a split rating (e.g. medium on the event, lower on its effects), keep the chip short and explain the split in the "why" line.

## Each edition
- Check every source link opens. Reuters, ISW (understandingwar.org) and Caliber.az block automated checks, so list those for the editor to click.
- Add the previous edition to "Previous editions → Biweekly Conflict Insights" in the footer (newest first), above the Weekly Brief archive.
- Remove any draft banner and `noindex` tag before publishing.
